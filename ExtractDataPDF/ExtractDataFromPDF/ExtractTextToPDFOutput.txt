1. Visão Geral 
 
Projeto para criação de uma solução para o gerenciamento dos contratos de 
concessionárias elétricas do grupo Prysmian. O projeto prevê a gestão dos preços dos contratos 
com base na aplicação das fórmulas de reajuste do site COGE aplicando as variações padrão da 
COGE referente ao mês e oferecer a opção de simular os valores. Será possível também gerenciar 
a demanda ainda restante de faturamento futuro por mês com base na data de encerramento do 
contrato. 
Será criada uma planilha em Excel com rotinas em VBA para atender os requisitos 
necessáros. 
2. Requisitos Funcionais 
2.1. Cadastro de Contratos 
 
Os contratos devem ser cadastrados na planilha, de maneira que será feita a importação 
dos dados necessários através do arquivo de contrato no formato PDF. O conteúdo do arquivo 
PDF pode estar de duas formas, como texto comum ou como imagem, para os dois casos deverá 
ser usada alguma ferramenta à parte para extração dos dados de texto do arquivo PDF, mas para 
o caso de arquivo PDF com imagem a ferramenta de extração deverá conter a funcionalidade de 
extração de texto de imagem conhecida como OCR.  
Na sheet principal da planilha deverá haver um botão para o cadastro de um novo contrato 
onde, na tela de cadastro, será informado o cliente, número do contrato e o local do arquivo PDF. 
A aplicação irá obter as informações necessárias do contrato e irá guardar os dados em uma sheet 
de cadastros e parametrizações. Caso algum dado não seja obtido será feito a entrada manual do 
dado. Será criada uma rotina de importação do arquivo PDF para cada contrato, caso mais de um 
cliente possua um modelo de arquivo semelhante ao outro será usada a mesma rotina de 
importação. Deverá ser criada uma tabela de parametrização para vincular o cliente à rotina de 
importação do arquivo PDF. Os seguintes dados serão necessários para a importação do arquivo 
PDF:

2.2. Atualização de Dados 
 
A planilha deverá conter na sheet principal um botão para a atualização de dados 
complementares que serão usados para os cálculos de reajuste de preço e geração de 
conhecimento. Ao clicar no botão será exibida uma tela para informar os arquivos de entrada e os 
mesmos serão processados um de cada vez segundo o seu propósito. A importação deverá ser 
gravada como histórico com exceção do de/para de produtos, de maneira que para o 
processamento do contrato no mês atual deverá ser considerado a importação do último mês. Isso 
devido ao fato de que será possível refazer o processamento de um contrato e deverá ser 
considerado os dados da época que foi feito o processamento inicial daquele contrato. 
 
2.2.1. De / Para Produto Cliente x Produto Prysmian 
 
O código de produto compreendido pelo cliente é diferente do código de produto 
compreendido pela Prysmian, mesmo sendo fisicamente e descritivamente o mesmo produto, de 
maneira que na tela de importação dos dados deverá ser selecionado o arquivo de origem dos 
dados, o sistema deverá validar o arquivo seguindo um padrão a ser definido e importar os dados 
para a sheet de cadastros auxiliares e parametrizações.  
O arquivo deverá conter os dados de código de produto do cliente x código produto 
Prysmian referente a todos os contratos em vigência na companhia.

2.4.3. Processamento Contratos Período Atual 
 
Na sheet de análise de contratos deverá ser disponibilizado um botão para seleção dos 
contratos a serem processados, de maneira que ao clicar no botão deverão ser listados todos os 
contratos cadastrados e deverá ser possível selecionar quais contratos serão processados naquele 
momento, deverá ser possível selecionar todos os contratos de uma vez. 
O processamento dos contratos consistem em obter as informações de cada contrato e 
cada item do contrato, buscar as informações de de/para de produtos, buscar as informações dos 
produtos, buscar as informações de faturamento de produtos e aplicar as fórmulas de preço com 
base no último processamento feito para aquele contrato levando em consideração que a 
periodiciadade de cada contrato varia, de maneira que deverá ser verificado se o contrato deverá 
ser processado naquele mês.  
O cálculo de processamento do contrato poderá ser feito de duas maneiras, o preço real 
que leva em consideração às variações da fórmula COGE ou simulação que levará em 
consideração as variações informadas pelo usuário que está operando a planilha. Para que o 
cálculo esteja correto é necessário sempre atualizar as variações das fórmulas COGE como 
descrito no item 2.3. 
A sheet de análise também conterá um botão para salvar os dados processados, de 
maneira que sempre que algum contrato for processado será necessário clicar no botão salvar para 
gravar os dados na sheet de base de dados históricos. Caso já exista algum registro na base de 
dados os dados serão sobrescritos.

2.4.4. Reprocessamento Contratos 
 
Na sheet principal da planilha deverá haver um botão para o reprocessamento de contratos 
onde será chamada a rotina para reprocessar os contratos de períodos anteriores ao mês atual 
respeitando sempre a periodicidade do contrato. Deverá ser possível selecionar o período e os 
contratos que deverão ser processados. O processamento consiste no mesmo descrito no item 
2.4.3, lembrando que é necessário sempre reajustar as variações das fórmulas COGE como 
descrito no item 2.3 para os dados do período que se está necessitando reprocessar os contratos. 
Após feito o reprocessamento dos contratos será exibia a sheet de análise dos contratos e o 
usuário poderá aplicar a simulação de preço para aquele determinado contrato.  
Para este processo de reprocessamento de contrato deverá ser marcado para cada 
contrato processado o mês e ano de referencia ao qual o contrato está sendo processado para que 
quando os dados sejam gravados seja sobrescrevido os dados de processamento do contrato na 
base de dados histórica para o mês reprocessado. 
Os cálculos para referência do reprocessamento de algum contrato deverão levar em 
consideração o ano e mês anterior ao que se está fazendo o reprocessamento para as informações 
de preço anterior, faturamento e custo do produto.  
O usuário deverá ter em mente que efetuar o reprocessamento de um contrato em 
determinado mês deverá ser feito o reprocessamento dos meses seguintes para que os dados 
sejam consistentes com o preço formado a partir do ponto em que fez o primeiro reprocessamento 
daquele contrato.

3.2. Segurança 
 
A planilha deverá ter a pasta de trabalho (workbook) e as planilhas (sheets) bloqueadas 
com a mesma senha. Sempre que um processamento for executado deverá ser feito o bloqueio 
das sheets. Será permitido apenas filtros nas tabelas das sheets, de maneira que caso haja 
necessidade de os dados deverá ser exportado para outra planilha de Excel. 
 Todas as fórmulas da planilha deverão ser aplicadas em VBA e depois os dados aplicados 
como valor com exceções a fórmulas que precisam ser recalculadas com imput do usuário no 
momento da análise.
